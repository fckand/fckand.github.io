# КОНТЕКСТ ПРОЕКТА

Проект рассматривает 4 основные технологии переработки пластика:
1. Механическая переработка (сортировка, измельчение, гранулы)
2. Химическая переработка (деполимеризация в мономеры)
3. Пиролиз (нагрев без кислорода → топливо, газ, углерод)
4. Энергетическая утилизация (сжигание для получения энергии)

Примеры из России:
- ЭкоЛайн-ВторПласт (Егорьевск) — 47 тыс. т/год гранул, оптика + нейросети
- Локопласт (Ижевск) — полный цикл от бутылок до стройматериалов

Ключевой вывод: для России оптимален ПИРОЛИЗ из-за огромных расстояний, слабого раздельного сбора и возможности утилизировать грязные/смешанные пластики локально с получением топлива.

1. **Визуальный стиль:**

   - Диаграммы и графики: анимация появления при скролле (intersection observer)
